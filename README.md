# 🎨 BrandCraft AI
### Empowering Creative Artists | Your Creativity. Your Identity. Your Brand.

BrandCraft AI is an interactive, AI-inspired creative branding platform designed to help artists, designers, and creative individuals build and manage their personal brand identity.

The platform brings multiple creative tools together in one place, allowing users to explore artwork, generate logo concepts, discover color palettes, develop their creative identity, create marketing captions, and organize their artwork portfolio.

Built using Python and Streamlit, BrandCraft AI provides a modern, user-friendly workspace that makes creative branding easier and more accessible.

---

## 🌟 Project Overview

In today's digital world, artists and designers need more than creativity to establish their identity. They also need a recognizable brand, consistent visual elements, effective marketing content, and a professional portfolio.

BrandCraft AI aims to simplify this process by providing a unified creative workspace with seven dedicated studios.

**Main Objective:**
To empower creative individuals with accessible digital tools that help them transform their artistic vision into a consistent and professional brand identity while preserving their originality.

---

## ✨ Key Features

BrandCraft AI consists of seven interactive modules:

### 1. 🏠 Dashboard
- Centralized creative workspace.
- Quick access to all seven creative studios.
- Modern and visually appealing interface.
- Easy navigation between different tools.

### 2. 🧠 ArtSense AI
- Upload artwork for visual analysis.
- Explore image characteristics and visual composition.
- Analyze image properties such as brightness, contrast, and saturation.
- Discover dominant colors.
- Receive artwork-related insights and suggestions.

### 3. ✨ Logo Studio
- Create personalized logo concepts.
- Enter brand names and taglines.
- Choose different logo styles.
- Customize background, logo, and text colors.
- Select logo layouts and symbols.
- Generate downloadable logos in PNG and SVG formats.

### 4. 🎨 Color Studio
- Upload images to extract dominant colors.
- Discover color combinations from artwork.
- Explore visual color palettes.
- Support consistent color selection for creative branding.

### 5. 🧬 Creative DNA
- Develop a personal creative identity profile.
- Explore artistic preferences and branding characteristics.
- Organize creative identity information.
- Help artists understand their individual visual style.

### 6. 📢 Marketing Studio
- Generate creative marketing caption ideas.
- Use ready-made caption templates.
- Edit generated captions.
- Download marketing captions as text files.
- Support artists in presenting their work online.

### 7. 🖼️ Portfolio Studio
- Upload multiple artworks.
- Add artwork titles and descriptions.
- Organize creative projects in a digital gallery.
- View uploaded artwork collections.
- Delete artwork when required.
- Export portfolio information.

## ⚙️ Installation and Setup

Follow these steps to run BrandCraft AI on your local machine.

### Prerequisites

Make sure you have installed:

- Python 3.10 or later
- pip (Python package installer)
- Git
- Visual Studio Code (recommended)

### Step 1: Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/piumandal/BrandCraft_AI.git
```

### Step 2: Navigate to the Project Directory

```bash
cd BrandCraft_AI
```

### Step 3: Install Dependencies

```bash
pip install streamlit pillow
```

Alternatively, if you have a requirements.txt file:

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

```bash
python -m streamlit run app.py
```

### Step 5: Open the Application

Streamlit will provide a local URL, usually:

```text
http://localhost:8501
```

Open this URL in your web browser to start using BrandCraft AI.
